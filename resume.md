## 🚀 Open Source Contributions

### ORE (One Render Each) – [Laravel Package](https://github.com/shubhcredit/ore)
 Developed a Laravel package to simplify and automate API development. ORE 	handles complete CRUD operations—including validation, relationships, create, 	update, view, and delete—without the need to write code in controllers, requests, 	or services.
- Enables fully functional APIs by defining logic only in the model.
- Built-in support for authentication, authorization, and permission checks.
- Includes frontend rendering permissions to manage access control effective.
- Designed to reduce repetitive code and accelerate module development in Laravel projects.
